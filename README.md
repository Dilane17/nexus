# Nexus — P2P Lending Bénin

## Prérequis
- Node.js 18+
- Flutter 3.x
- PostgreSQL 16
- Redis

## Installation
```bash
npm run install:all
```

## Lancement
```bash
# Backend + Dashboard (un seul terminal)
npm run dev

# App Flutter (terminal séparé)
cd frontend/nexus && flutter run
```

## Services
- Backend API : http://localhost:3000/api/v1
- Swagger : http://localhost:3000/api/docs
- Dashboard Admin : http://localhost:3001
